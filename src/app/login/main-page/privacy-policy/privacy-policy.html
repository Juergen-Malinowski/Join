2. About this project

Join is an educational web development project originally created as part of a collaborative team project during professional training. The application is now presented as a portfolio and demonstration project.

The project data included in the published version has been reviewed. Names, email addresses, telephone numbers, and other identifying information contained in the demonstration data have been anonymized or replaced with fictitious data and do not represent real persons.

Users who create their own account or enter information into the application may, however, provide personal data themselves. Users are therefore requested not to enter sensitive personal data or personal data of third parties into this demonstration application.

3. Data processed when using Join

3.1 Registration and authentication

Join uses Firebase Authentication for user registration and login.

When a user creates an account, the following data may be processed:

  • Name
  • Email address
  • Authentication credentials
  • A technical user identifier (UID) assigned by Firebase
  • IP address and technical authentication information

Passwords are processed by Firebase Authentication and are not stored directly in the application database.

Registered users can log in using their email address and password.

Join also provides an anonymous guest login. In this case, Firebase creates a temporary anonymous user account. The application is designed to remove this anonymous account when the guest logs out.

3.2 Application data

Join uses Google Cloud Firestore to store application data.

Depending on how the application is used, this may include:

  • Contacts
  • Names
  • Email addresses
  • Telephone numbers
  • Tasks and task descriptions
  • Task priorities and status information
  • Task assignments
  • Subtasks

The published demonstration data contained in the application is fictitious. Users who create or edit their own content are responsible for the information they enter.

4. Purpose of processing

Personal data is processed only insofar as necessary to provide the functions of the application, including:

  • Creating and managing user accounts
  • Authenticating registered and guest users
  • Storing and displaying contacts and tasks
  • Assigning contacts to tasks
  • Maintaining the technical operation and security of the application

5. Firebase and Google

Join uses Firebase services provided by Google, in particular Firebase Authentication and Cloud Firestore.

In connection with these services, personal data may be processed by Google on behalf of the operator of this application. Google generally acts as a processor for customer data processed through Firebase services.

Firebase Authentication processes authentication data, including email addresses, passwords, IP addresses, and technical information required for account security and abuse prevention.

Firebase Authentication is operated from data centers in the United States. Cloud Firestore may process data at Google Cloud locations depending on the configuration of the Firebase project.

Where personal data is transferred outside the European Union or the European Economic Area, Google provides contractual safeguards, including Standard Contractual Clauses where applicable.

6. Cookies, analytics and tracking

Join does not use advertising, analytics, or marketing tracking tools such as Google Analytics.

Firebase Authentication may use technically necessary browser storage or similar mechanisms required to maintain authentication sessions and provide login functionality.

No data is processed by this application for advertising or behavioural profiling purposes.
